# Gemini video seed images

AI-generated fictional H-E-B supermarket scenes, made with an image-generation tool, for developing demo footage in Gemini. These are source assets, not deployed app media. Each prompt file includes the image prompt and a suggested Gemini animation prompt.

- [v1: three shoppers](heb-three-shoppers-v1.png) ([prompt](heb-three-shoppers-v1-prompt.txt)): framing liked, lineup rejected as staged.
- [v2: cart, basket and partner](heb-checkout-candid-v2.png) ([prompt](heb-checkout-candid-v2-prompt.txt)): sparse action liked, but it implied self-checkout and showed already-bagged groceries.
- [v3: staffed checkout](heb-staffed-checkout-v3.png) ([prompt](heb-staffed-checkout-v3-prompt.txt)): cashier behind the register and conveyor, cart with unbagged groceries. Latest seed.

Ian later supplied the People in Store clip now in the app; whether it came from one of these seeds is unconfirmed.

For future seeds: keep people sparse, naturally oriented and visually separated, and favor a plausible retail workflow over staged poses or forced full-body visibility.
